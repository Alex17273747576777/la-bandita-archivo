## ❓ Basement questions

**Do I need a server to live these guides?**
No: every piece says what it asks. The bookcase (17) and this machinery ask for a machine on; the remote (23) asks for somebody else's room. Start with what you already have.

**And the privacy of so many servers?**
The workshop's rule counts double here: every open port is a door with a key. Backups, own passwords and updates up to date — the basement doesn't forgive carelessness.
