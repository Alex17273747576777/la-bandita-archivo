# wotoha · akachiina

*Manga downloader CLI with Aidoku (WASM) extensions*

**Racimo:** reemplazo-del-stack · **Repositorio:** `akachiina/wotoha` · **Estado:** vivo · **Medido:** 2026-11-05 11:42 UTC

## Qué es, según quien lo hace

> - 140+ sources: official Aidoku index plus third-party repos (sources repo add) - 5 output formats: raw, epub, cbz, cb7, pdf, all with ComicInfo.xml metadata - 3 packaging modes: per chapter, per volume, or single file for the whole manga - Language filter: per-run --language for multi-language sources (MangaDex, MangaPlus, MangaFire...) - Resume built in: re-run the same command, finished chapter
