### Para qué sirve

MIYO es un fork refinado de Usagi que se ha optimizado específicamente para dispositivos antiguos, bibliotecas masivas y conexiones inestables. Hereda la filosofía de Usagi (sin fuentes integradas, el usuario añade las que desea) pero añade mejoras nativas de rendimiento que lo hacen significativamente más rápido en hardware modesto.

Es una opción para quien usa un teléfono antiguo o tiene una biblioteca muy grande y necesita algo ligero.

### Cómo se usa

1. Se instala la APK o se compila desde el repositorio.
2. Al igual que Usagi, no trae fuentes preinstaladas: el usuario añade las que quiera.
3. Se configuran las extensiones y se empieza a leer.
4. Las mejoras de rendimiento se aplican automáticamente en hardware modesto y conexiones inestables.

### Lo que conviene saber antes

- Tiene 299 descargas, proyecto pequeño pero enfocado en un nicho específico.
- Última versión v0.0.5-1 del 15 de junio de 2026.
- Optimizado para dispositivos antiguos y bibliotecas masivas.
- Hereda la filosofía "viene vacío" de Usagi: control total sobre las fuentes.

### Cuándo no vale la pena

Si tienes un dispositivo moderno y una biblioteca pequeña, las optimizaciones de MIYO no se notarán y podrías usar Mihon o Komikku directamente. Si no quieres configurar fuentes manualmente, busca un lector con fuentes preinstaladas. Y como siempre: no trae contenido, tú pones las fuentes.
