# WoodicIPTV · Woodic-Way

*WoodicIPTV is an open-source Android IPTV and radio player that supports M3U playlists. Features include live TV streaming, radio playback, favorites management, offline cache, channel testing, Persian language support, and country-based filtering. Perfect for streaming live TV channels and internet radio*
