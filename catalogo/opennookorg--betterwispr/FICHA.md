# betterwispr · opennookorg

*Free, open-source, local-first dictation app for macOS. Hold a shortcut, speak, and text is typed into any app. On-device speech-to-text with Whisper, Parakeet and Apple speech. Private, offline, open-source Wispr Flow alternative.*

## Cómo se consigue

- Download the latest release · Website · Changelog
- 1. Download the DMG from Releases and drag BetterWispr to Applications.
- 3. Pick a model in **Models**. Apple on-device needs no download; Parakeet and Whisper download once, then work offline.
- Built-in models only touch the network when you explicitly download one.
