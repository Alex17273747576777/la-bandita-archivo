## ❓ Big-door questions

**Why "declared genealogy" and not certified?**
Because honesty distinguishes: GitHub certifies git forks; catalogs declare project lineages. Both count — but each listing says which of the two holds it up. Fly low: the source gets labeled too.

**Why is Dantotsu listed via its updater?**
Because that's where it lives: the app gets handed out there. Listing the app by a repo it no longer uses would be pinning the portrait on the wrong house.
