## [ИНФО] Закрытие двухнедельки: 80 проверенных публикаций и перепись из 1 008 записей на 100 % (срез: 15.09.2026)

**Что это:** закрывающий акт общественного проекта open-source рекомендаций. Это не мой софт и не моей группы: перепись сторонних репозиториев, измеренная и опубликованная с датой. Маленький проект друзей, официальной поддержки нет — сказано сразу.

**Как проверялось:** GitHub REST API (звёзды + активность) + пробы живости каждого дома + перекрёстный HTML-скрейпинг 351 сомнительного случая (первый проход API упёрся в лимит посреди переписи; ни один ноль не опубликован без перепроверки). Кузницы вне GitHub сканировались напрямую; версии — через публичный API каждой кузницы, без чужих ключей.

## Числа

- 1 008 записей исходника отвечены на 100 %.
- 136 кузниц и сайтов просканированы: 129 живых · 5×403 (статус не объявляется) · 2 мертвы, с актом.
- 351 подозрительный ноль перепроверен; 7 настоящих нулей; 0 выдуманных.
- 80 публикаций × 2 платформы, близнецы проверены побайтово; топ-20 без дублей (зеркала и переименования считаются один раз).

## Метод и урок

«Лучше того, что было, — никогда не идеально»: правки с датой, никогда молча; выдуманных состояний нигде; ноль в пробе = акт, не вымысел.
