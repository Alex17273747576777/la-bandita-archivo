## 📜 Qué era GLTools (historia)

[Reporte externo] GLTools clásico (XDA, ~2016) era un optimizador gráfico de código cerrado, con hilo largo y APK. Esta guía **no abre** el hilo de XDA como destino de descarga. Nombrar la historia ≠ mandarte al APK de 2016.

Un módulo Magisk «GLTools» de 2020 es un port de alguien. No es el autor original firmando en 2026.

## 🧲 Lo que hay en GitHub hoy

https://github.com/darek2015/GLTools — muerto de hecho (2020), aunque no esté el flag archived.

https://github.com/i-Taylo/iUnlockerGL — vivo hasta diciembre 2025. Description: spoof de OpenGL/Vulkan/modelo/CPU/RAM. Requiere root (Magisk v26.4+ o KernelSU, según README de búsqueda; el README HTML no se recorrió entero hoy más allá de la API y el recorte).

[Inferencia] Spoofear GPU para «desbloquear gráficos» en juegos es exactamente el tipo de herramienta que las tiendas de mods venden con malware de regalo. Aunque el repo sea público, **esta guía no receta flashearlo**. G-002: no dañar. Root + Zygisk + un ZIP de GitHub es irreversible si sale mal (G02).
