## Cómo se conecta uno de los que faltan

```
# 1. pegar la llave en la bóveda
echo 'NOTION_KEY="ntn_..."' >> ~/.boveda/tokens.env
# 2. volver a probar: el cliente la recoge sola
python3 tools/mcp_conectar.py --probar
```

Sin llave, el estado es `401` y así queda escrito. Un conector que no abre sesión no se declara conectado.
