## Cómo se conecta uno que pide credenciales

```
python3 tools/mcp_conectar.py --llamar https://mcp.linear.app/mcp tools/list '{}'
```

El encabezado de autorización se añade al cliente cuando el dueño pegue la llave; mientras tanto, el estado es `401` y así queda escrito.
