## El encargo

El dueño pidió una publicación completa de Facebook sobre `krishna3163/OmniShizuku` porque, según lo que le

## Lo que salió al medir

**La mitad del mensaje es cierta y la otra mitad no.** El cambio existe, está fechado y es de hoy: el commit
`cce6249a`, a las 10:47 UTC, cambia la cadena de compilación para publicar **solo la compilación de
depuración**. Antes se publicaban tres archivos por entrega (depuración ~56,8 MB, producción ~22,3 MB y una
copia con nombre corto). Desde ese minuto, uno: ~57 MB.

Pero no es «un cambio mejor» para quien descarga:

- el archivo pasa de 22.356.386 a 57.021.147 bytes (2,55 veces), porque la compilación de producción llevaba
  `minifyEnabled` y `shrinkResources` y la de depuración no;
- **la firma cambia en cada compilación**: comprobado bajando `1.0v` (10:52 UTC) y `v1.0.7-dev` (14:12 UTC) y
  comparando los bytes del certificado. Los dos dicen `CN=Android Debug` y tienen contenido distinto, porque
  la cadena de compilación genera un almacén de claves nuevo por ejecución cuando no hay secretos de firma.
  Consecuencia: para actualizar hay que desinstalar;
- la etiqueta `latest` reemplaza su archivo en cada compilación, así que un enlace fijo apunta a paquetes
  distintos con firmas distintas.

**La evolución de fondo sí existe, y no está en la lista de funciones.** El paquete publicado lleva dentro
`assets/shevery-stub.apk` y `assets/shevery-dhizuku-stub.apk`. El módulo `stub/build.gradle` los compila con
las identidades `moe.shizuku.privileged.api` y `com.rosan.dhizuku` (namespace `shevery.compat.stub`,
`versionName 14.5.0`, `versionCode 2000000000`). Es decir: el proyecto puede ocupar la identidad de Shizuku y
de Dhizuku en el teléfono, que es lo que convierte a un gestor en un sustituto.

**Tres funciones nuevas el mismo día:** `d32766e9` a las 11:43 (control de corrientes de audio), `431fd95f` a
las 13:27 (ventana flotante universal) y `937fc143` a las 13:57 (consola local y consola por intenciones).

## Los tres cotejos contra el README

1. **Versión mínima:** el README dice API 21; el `build.gradle` de la raíz dice `minSdk = 26`,
   `targetSdk = 37`, `compileSdk = 37`. Un Android 5, 6 o 7 no la instala. `PONYTAIL.md` ya dice 26/37: el
   desactualizado es el README.
2. **Nombres de archivo:** el README manda bajar `manager-debug.apk` o `manager-release.apk`; las entregas de
   hoy se llaman `omnishizuku-<etiqueta>-debug.apk` y el `release` ya no se publica.
3. **Telemetría:** el README afirma «sin telemetría — sin análisis, sin rastreo y sin recogida de datos». El
   `manager/build.gradle` incluye `firebase-bom 34.19.0`, `firebase-crashlytics` y **`firebase-analytics`**;
   `ShizukuApplication.kt` línea 72 hace `setCrashlyticsCollectionEnabled(true)` al arrancar; hay un
   `google-services.json` versionado; y la búsqueda de `setAnalyticsCollectionEnabled` no devuelve nada. En
   la pieza no se reproduce la clave de API del archivo.
