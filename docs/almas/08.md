*🛠️ Seis órdenes para comprobar un cliente de red*

1. `sha256sum archivo` antes de instalar. En un programa que va a ver todo tu tráfico, esto no se salta.
2. Busca el adjunto terminado en `.sha256`, `.asc`, `.sig` o `sums` en la página de entregas.
3. `sha256sum -c archivo.sha256` — `OK` o `FAILED`.
4. `apksigner verify --print-certs archivo.apk` y compara la huella entre versiones.
5. Si el programa se instala por un script: guarda el script y compáralo con el del repositorio, línea por línea. Un `curl | bash` de un tercero no se puede verificar de ninguna forma.
6. Si no hay suma, pídela en las incidencias. La respuesta —o el silencio— informa.
