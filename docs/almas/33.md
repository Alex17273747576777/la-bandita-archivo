*🛠️ Seis órdenes para comprobar una extensión de saltos*

1. Si es una extensión de navegador, instálala desde la tienda oficial o desde el archivo del autor, nunca desde un enlace de un foro.
2. `sha256sum archivo` si la bajas del repositorio.
3. Busca `.sha256`, `.asc`, `.sig` o `sums` en la página de entregas.
4. Mira a qué servidor consulta la lista de saltos: eso sí tiene consecuencias de privacidad.
5. En una copia con el mismo nombre de otro autor, compara el historial con el original: lo que cambió está ahí.
6. Si no hay suma, pídela.
