*🛠️ Seis órdenes para comprobar una herramienta de documentos*

1. `sha256sum instalador` antes de pasarle un documento personal.
2. Busca `.sha256`, `.asc`, `.sig` o `sums` en la página de entregas.
3. `sha256sum -c archivo.sha256` — `OK` o `FAILED`.
4. Si el programa corre en un servidor: fija la imagen por resumen, nunca `latest`, y no lo expongas a internet con documentos dentro.
5. Mira si necesita red. Una herramienta de OCR local que pide internet, dice mucho.
6. Si no hay suma, pídela. Aquí el archivo ve lo que no se puede reenviar.
