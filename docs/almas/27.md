*🛠️ Seis órdenes para comprobar un lector de novelas*

1. `sha256sum archivo` antes de instalarlo.
2. Busca `.sha256`, `.asc`, `.sig` o `sums` en la página de entregas.
3. `sha256sum -c archivo.sha256` — `OK` o `FAILED`.
4. Mira cuándo fue la última entrega. Un lector sin entregas hace dos años sigue funcionando con los sitios que ya conoce y falla con los nuevos.
5. Si el lector baja texto de un sitio, el segundo eslabón no viene firmado.
6. Si no hay suma, pídela. Y si el proyecto está parado, la respuesta puede tardar meses.

**«¿Con cuál me quedo?»** Con el que siga funcionando con tu sitio. Y mira si publica suma.
